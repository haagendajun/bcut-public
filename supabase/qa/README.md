# QA 화면 (슈파베이스 DB 시험용)

```bash
cd supabase/qa && python3 -m http.server 8791 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:8791/ 열기
```
- 본인 계정(대시보드에서 만든 이메일·비밀번호)으로 로그인한다. 비밀번호는 이 화면에서만 입력한다.
- 1) 테스트 데이터 올리기 → 2) 조회·셀렉 → 3) 막혀야 정상인 동작(삭제·수정·잘못된 값).
- 테스트 데이터는 이름이 `QA_`로 시작한다. 앱에서는 삭제할 수 없으므로 정리가 필요하면 관리자(SQL)로 지운다.
