# ② 기준값 측정 방법 (T0.3)

> **이 측정은 하지 않기로 했다 (2026-10-20, 사용자 결정).** 그래서 "② 50% 단축"은 판정하지 않고 검증되지 않은 가설로 남는다. 아래는 나중에 시간을 확인하고 싶어질 때 쓸 수 있도록 남긴 방법이다.

**왜 필요한가:** 이 도구의 핵심 목표는 "② 1차 컷(명백한 B컷 걷어내기)을 **지금보다 절반 이하 시간**에 끝낸다"이다. 지금 ②가 한 장당 몇 초 걸리는지 잰 기록이 없어서, 도구를 써도 절반이 됐는지 **판정할 수 없다.** 이 숫자가 G3(출시 판단)의 가장 큰 빈칸이다.

## 1. 무엇을 재나 — ②의 시작과 끝

| | 정의 |
|---|---|
| **시작** | 행사 사진이 Capture One에 다 들어와 있고, **첫 사진을 B컷인지 보기 시작하는 순간** |
| **끝** | "이제 ②가 끝났다. 남은 컷으로 ③ 유사컷 비교를 시작해도 된다"고 생각하는 순간 (③ 작업을 시작하기 직전) |
| **뺄 시간** | 전화, 식사, 다른 일로 자리를 비운 시간. 스톱워치를 **일시정지**한다 |
| **포함할 시간** | 사진을 확대해 보는 시간, 망설이는 시간, 컬러 태그·별점 붙이는 시간 등 ② 작업에 쓴 모든 시간 |

가져오기(①)와 유사컷 비교(③)는 재지 않는다.

## 2. 어떻게 재나 — 휴대폰 스톱워치 하나로 충분

1. 행사 사진을 평소처럼 Capture One에 가져온다.
2. **스톱워치 시작** → 평소 하던 방식 그대로 ②를 한다. (이번에는 도구를 쓰지 않는다. 일부러 빨리하거나 꼼꼼히 하지 않는다.)
3. 자리를 비우면 **일시정지**, 돌아오면 다시 시작한다.
4. ②가 끝나면 **정지**하고 숫자를 적는다.

## 3. 무엇을 적나

[`eval/baseline.csv`](../eval/baseline.csv)에 행사마다 한 줄:

| 열 | 뜻 |
|---|---|
| 행사 | 이름 |
| 날짜 | |
| 사진수 | ②를 시작할 때 사진 장수 |
| 순소요(분) | 스톱워치에 찍힌 시간 (쉰 시간 제외) |
| 쉰시간(분) | 일시정지한 시간 (참고용) |
| 제외한컷 | ②에서 B컷으로 걷어낸 장수 |
| 방식 | 평소 어떻게 표시했는지 (예: 별점 1점, 빨강 태그, 따로 앨범) — 나중에 같은 방식으로 비교하려고 |
| 메모 | 특이사항 (매우 어두운 행사, 같은 포즈 많음 등) |

**장당 초 = 순소요(분) × 60 ÷ 사진수** (표 파일에서 계산하거나 제가 계산한다).

## 4. 어떤 행사로 재나

권장: **앞으로 실제로 하는 행사 3건**(가능하면 소 약 300~400장, 중 약 700~1000장, 대 약 1200~1500장)에서 ②를 **평소처럼 하면서 스톱워치만 켠다.** 추가 작업이 없다.

- **이미 끝난 행사를 다시 하지 않는다.** 한 번 본 사진은 기억 때문에 더 빨라져서 기준값이 너무 짧게 나오고, 그러면 도구가 "절반이 안 됐다"고 잘못 판정될 수 있다.
- 행사 규모가 다르면 장당 시간이 다를 수 있어서, **나중에 도구를 쓰는 행사와 비슷한 규모끼리 비교**한다.
- 사진 수가 적어도(예: 100장대) 기록은 남긴다. 규모별 경향을 보는 데 쓴다.

## 5. 도구를 쓴 뒤에는 같은 방식으로 잰다

도구를 쓰는 행사에서는 같은 스톱워치로 **②의 시작부터 끝까지**를 잰다. 이 시간에는 도구 때문에 드는 시간(분석 대기, 반영, 후보·확인 앨범 확인, 오탐 살리기, 필요한 경우 키워드 만들기)도 **모두 포함**한다. 도구가 빨라도 대기 시간이 길면 이득이 줄기 때문이다.
- 처음 쓰는 카탈로그의 키워드 만들기는 한 번만 드는 시간이므로 **따로 적는다**(행사당 시간에서 뺀 값과 포함한 값을 둘 다 기록).
- 비교: `(도구 쓴 ② 시간) ÷ (같은 규모 기준값) ≤ 50%`이면 목표 달성. 행사 기록([event-record.md](event-record.md))의 후보 앨범 확인 시간과 함께 본다.

## 6. 주의

- 한 번의 측정은 사람 컨디션에 따라 달라진다. **3건의 평균**으로 판단한다.
- 기준값이 너무 짧거나 길게 잡히지 않도록, **측정한다는 이유로 평소와 다르게 하지 않는다.**
- 이 숫자가 없으면 G3의 "50% 단축"은 판정할 수 없다. 도구가 눈 감김을 잘 잡아도(정탐 94%) 시간이 줄었는지는 별개다.
