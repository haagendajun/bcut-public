# Capture One 표시는 기존 `apply`·`rollback`을 그대로 쓰고, 키워드는 한글 이름 세 개

셀렉·보류·버릴 컷을 Capture One에 붙일 때 새 연동 코드를 만들지 않고 **기존 `run_apply`(백업·검증·재실행 안전)와 `run_rollback`을 그대로 부른다.** 달라지는 것은 "무엇을 붙일지"(계획)뿐이고, 판정 결과 대신 사용자의 표시로 `파일 → [키워드]`를 만든다. 키워드는 `bcut-셀렉`, `bcut-보류`, `bcut-버릴컷` 세 개이고 별점·컬러 태그는 건드리지 않는다. 한글 이름은 `osascript` 인자 전달에서 깨지지 않음을 확인했지만 Capture One 안에서의 동작은 사람이 확인해야 하며, 안 되면 영문 이름으로 바꾼다(한 곳: `ui/capture.py`의 `KEYWORDS`). 기록: 2026-10-20.


**추가 (S6-B, 2026-10-20):** 사용자가 세션을 많이 써서 세션도 지원한다. 문서 종류를 확인해 세션이면 사진 읽기 스크립트를 바꾸고 카탈로그 백업(카탈로그 전용 명령)은 생략하며 `bcut-backup.json`(직전 키워드 기록)으로 되돌린다. 카탈로그 읽기 스크립트는 그대로다.
