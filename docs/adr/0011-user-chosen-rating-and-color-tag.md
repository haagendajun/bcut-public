# 별점·컬러 태그는 사용자가 고른 값만, 기본은 안 줌 (ADR-0010 보완)

처음에는 Capture One의 별점·컬러 태그를 건드리지 않기로 했지만(ADR-0010, PRD FR-28), **2026-10-20 사용자가 직접 정하는 방식으로 바꿨다**: 표시 종류(셀렉·보류·버릴 컷)마다 별점(1~5)과 컬러 태그(빨강·주황·노랑·초록·파랑·분홍·보라)를 사용자가 고른다. 더 나중에 정한 것이 이긴다.

안전장치: ① **기본은 안 줌**(고르지 않으면 키워드만). ② 이미 별점·컬러 태그가 있는 사진은 건너뛰고, "바꾸기"를 켠 때만 덮어쓴다. ③ 주기 **전에 이전 값을 `bcut-style-backup.json`에 먼저 저장**하고, 저장하지 못하면 아무것도 안 준다. ④ 준 뒤 다시 읽어 확인한다. ⑤ 되돌리기는 현재 값이 우리가 준 값 그대로인 사진만 이전 값으로 돌리고, 그 사이 사용자가 바꾼 것은 건드리지 않는다. ⑥ 키워드가 모두 붙은 뒤에만 준다. 컬러 태그 번호는 빨강=1만 실기로 확인했고 나머지(주황 2 … 보라 7)는 Capture One 순서를 따랐으므로 사람이 화면에서 확인한다. 기록: 2026-10-20.
