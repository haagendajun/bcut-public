# 올리기는 `ui/cloud.py` 한 파일, 로그인 토큰은 서버가 키체인에 직접 둔다

로컬 표시·훑기 기록을 DB에 올리는 통신은 파이썬 기본 `urllib`로, **`src/bcut/ui/cloud.py` 한 파일에서만** 한다(ADR-0003 구체화). 안전 시험의 네트워크 금지 목록에서 이 파일 하나만 예외다. 허용 주소는 `https://*.supabase.co`뿐이고 공개용 열쇠만 쓴다.

ADR-0006은 토큰을 Electron safeStorage에 둔다고 했지만, 로그인 요청을 보내는 쪽이 파이썬 서버이므로 **서버가 macOS 키체인(`security` 명령)에 갱신 토큰만 직접 저장**하는 것으로 바꾼다. 비밀번호는 어디에도 저장하지 않는다. 대가: 명령 인자로 토큰이 잠깐 보일 수 있다(한 사용자 Mac, 수명 있는 갱신 토큰). 새 라이브러리를 피하려는 선택이며, 이의가 있으면 되돌린다. 기록: 2026-10-20.
