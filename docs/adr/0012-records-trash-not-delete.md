# "지우기"는 파일을 지우지 않고 앱 휴지통으로 옮긴다

사용자가 앱에서 기록을 날리고 싶어 했다(2026-10-20: "지금 셀렉된 거 기록을 날리고 싶은데 기능이 없어", 지우기 포함 요청). 삭제 없음 원칙(ADR-0005)과 안전 시험의 삭제 호출 금지를 지키기 위해 **기록 파일(표시·훑기·Capture One 반영 기록)을 `<data-dir>/trash/`로 옮기고 복원할 수 있게** 한다. 표시만 날리고 싶을 때는 **모두 해제**(취소 줄 추가, 이력 보존)를 쓴다. 사진 파일, Capture One 안의 값, 클라우드 DB 행(삭제 권한 없음)은 건드리지 않는다. 휴지통을 자동으로 비우지 않는다. 기록: 2026-10-20.
