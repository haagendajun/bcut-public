# 정답 B컷 표시 방법 (라벨링 가이드)

> 작성일: 2026-10-19 · 대상: `~/Desktop/260212 행사 B STRX SJ 복사본` (CR3 145장)
> 목적: devplan T0.6(정확도 측정)과 T1.11~1.13(보정·평가)에 쓸 **정답 데이터**를 만든다.
> 근거: 탈락 사유가 어디에도 남아 있지 않다 ([env.md](env.md) 4장). 별점 5점 16장만 있고 나머지 129장은 사유를 알 수 없다.

## 1. 방식: Capture One 컬러 태그로 표시한다

| 방식 | 장점 | 단점 | 선택 |
|---|---|---|---|
| **A. Capture One 컬러 태그** | 평소 쓰는 화면에서 바로 표시, 앱을 오가지 않음 | 태그는 폴더가 아니라 **카탈로그 DB**에 저장됨 (3장 파일럿으로 확인). 카탈로그에서 읽는다 | **채택** |
| B. 파일명을 적는 표(CSV) | Capture One 저장 방식과 무관 | 사진 보면서 표에 파일명을 옮겨 적어야 해서 느리고 오타가 남 | A가 안 될 때 대안 |

기본안 A에서 표시한 결과는 `tools/export_labels.py`가 설정 파일(`.cos`)에서 읽어 CSV로 만든다. 사진과 설정 파일은 읽기만 한다.

**원칙**
1. **확실한 것만 B로 표시한다.** 조금이라도 망설여지면 "애매"로 표시한다. (애매는 집계에서 뺀다. 틀린 정답이 섞이는 것이 가장 나쁘다.)
2. **취향·구도 때문에 탈락한 컷은 B가 아니다.** 이 도구는 기술적 결함만 다룬다. 표시하지 않는다.
3. **기존 별점은 바꾸지 않는다.** 별점 5점 16장은 최종 선택 후보로 보고 그대로 둔다.
4. 이 행사 폴더에서 표시한 태그는 **정답용**이다. 나중에 도구 쓰기 테스트(`apply`)는 이 폴더를 한 번 더 복제해서 따로 한다.

## 2. 색과 의미

사유마다 색 하나를 쓴다. 색 이름은 제안이고, Capture One에서 쓰기 편한 대로 바꿔도 된다 (바꾸면 아래 표를 같이 고친다).

| 색 | 라벨 | 이 색을 붙이는 경우 | 이 색을 붙이지 않는 경우 |
|---|---|---|---|
| **빨강** | 눈 감김 | 주인공 인물의 눈이 반 이상 감겨 있다 (눈동자가 보이지 않거나 가려짐) | 웃느라 가늘게 뜬 눈 → **파랑** |
| **주황** | 흔들림 | 카메라 흔들림이나 피사체 움직임으로 윤곽이 번져 보인다 (100% 확대에서 확인) | 의도한 모션 블러 |
| **노랑** | 초점 실패 | 주인공(얼굴, 제품)이 아니라 배경이나 앞쪽에 초점이 맞았다 | 일부러 흐리게 한 보케 |
| **초록** | 노출 문제 | 심한 과노출·저노출로 복구가 어렵다 | 후보정으로 충분히 살릴 수 있는 정도 |
| **파랑** | **표정 주의** (정상) | 눈을 가늘게 뜬 웃음, 윙크, 시선을 아래로 둔 표정 등 **결함이 아니지만 눈 감김으로 오판되기 쉬운 컷** | |
| **보라** | **애매** | B인지 판단이 안 서는 컷 | |
| (태그 없음) | 정상 | 결함이 없다 | |

- **파랑(표정 주의)이 가장 중요하다.** 오탐은 가장 큰 손실인데 도구가 틀리기 쉬운 곳이 바로 여기다 (list_solution S2 한계). 이 컷을 모아야 도구가 이를 걸러내지 않는지 시험할 수 있다.
- 한 컷에 결함이 둘 이상이면 **가장 분명한 하나**만 붙인다. 나머지는 4장 메모에 적는다.
- 제품 컷(시계 등)에는 눈 감김이 없으므로 주황·노랑·초록만 쓴다. 인물이 없는 컷은 파랑을 쓰지 않는다.

## 3. 파일럿 결과 (2026-10-19 완료)

`PILOT` 카탈로그(현재 위치 `~/photo-select-data/catalogs/PILOT.cocatalog`, 처음에는 바탕화면에 만들었다)를 새로 만들어 행사 폴더를 **제자리에서** 불러오고, 5장에 컬러 태그를 하나씩 붙인 뒤 Capture One을 종료해서 확인했다.

| 확인한 것 | 결과 |

| **기존 별점 5점 16장이 카탈로그에서 보이나** | **아니오.** 카탈로그에는 별점 5가 0건이다. 가져올 때 `.cos`의 별점이 반영되지 않았다 |
| 색 번호와 색 이름 | 1 빨강, 2 주황, 3 노랑, 4 초록, 5 파랑으로 **사용자 확인 완료**. 6(분홍), 7(보라)은 기본 순서를 가정한 값이라 보라(애매)를 쓰면 본 작업 후 한 장으로 확인한다 |

**이 결과가 바꾸는 것**
1. 태그는 카탈로그에서 읽는다 (`export_labels.py --catalog`). 폴더 설정 파일에서 읽는 방식은 안 된다.
2. 표시 작업은 **PILOT 카탈로그에서** 한다. 화면에는 별점 5점이 보이지 않으므로, 아래 4장의 16장 목록을 따로 참고한다.
3. 별점은 `.cos`에서 읽는다 (스크립트가 둘을 합친다).
4. **S3 설계에도 영향이 있다.** 카탈로그 모드에서는 별점·태그가 카탈로그 DB에 있고 `.cos`에는 안 쓰인다. S3의 `apply`는 AppleScript로 카탈로그를 직접 조작해야 하고, 폴더의 설정 파일을 고치는 방식은 쓸 수 없다. (devplan T0.5에 반영)

**별점 5점 16장 (최종 선택 후보, 카탈로그에서는 안 보임):**
`PHB_7649, 7651, 7665, 7674, 7675, 7704, 7706, 7710, 7724, 7756, 7766, 7767, 7776, 7778, 7787, 7796`

**파일럿 태그 정리:** `PHB_7652, 7653, 7654, 7655, 7658`에 붙인 시험용 태그 5개는 본 작업 전에 지운다 (또는 새 PILOT 카탈로그를 다시 만든다).

## 4. 표시 절차 (파일럿 통과 후, 약 20~30분 **[제안]**)

### 1차: 전체 훑기 (약 10분)

1. 그리드가 아니라 **한 장씩 화면에 맞춰** 본다 (145장).
2. 눈에 띄는 결함만 표시한다. 눈 감김(빨강), 심한 초점·흔들림(주황, 노랑), 노출(초록).
3. **눈을 가늘게 뜬 웃음이나 의심스러운 표정은 바로 파랑 또는 보라**로 표시한다.

### 2차: 100% 확대 확인 (약 10~15분)

흔들림과 초점 실패는 화면 맞춤으로는 안 보이는 경우가 많다. 이 단계가 빠지면 "정상"으로 둔 컷 중에 숨은 결함이 섞여 **미탐 기준이 틀어진다.**

1. **별점 5점 16장**은 제외한다 (이미 최종 선택. 결함이 있으면 이 도구의 가장 큰 오류가 되므로 아래 3차에서 점검).
2. 나머지 중 **태그가 없는 컷**을 100%로 확대해 얼굴이나 제품의 눈에 띄는 부분의 초점을 본다. 장당 몇 초면 충분하다.
3. 결함이 보이면 해당 색을 붙인다. 판단이 안 서면 **보라**.

### 3차: 점검 (약 5분)

- 별점 5점 16장 중에 빨강·주황·노랑·초록이 붙은 것이 있으면 **충돌이다.** 어느 쪽이 맞는지 다시 본다 (선택된 컷에 결함이 있었는지, 표시가 잘못됐는지).
- 보라(애매)가 전체의 20%를 넘으면 기준이 너무 엄격한 것이다. 몇 장을 다시 보고 정한다.
- 완료 후 Capture One을 **종료**해서 저장을 확정한다.

### 메모 (선택)

복수 결함, 의도적 표정, 특이 사례는 파일명과 한 줄 메모로 적는다. `labels_note.md` 같은 아무 파일에 적어도 된다.

## 5. 라벨 파일로 바꾸기 (제가 처리)

표시가 끝나면 아래를 실행한다.

**Capture One을 완전히 종료한 뒤** 실행한다 (실행 중에는 DB 내용이 덜 저장되어 있을 수 있다).

```bash
python3 tools/export_labels.py "<행사 폴더>" --catalog <카탈로그.cocatalog> --out eval/labels_raw.csv
```

실제로 쓴 값 (2026-10-19, 위치는 이후 옮겼다):
- 행사 B: 행사 폴더 `~/photo-select-data/events/260212_행사 B_STRX_SJ` (처음에는 바탕화면, 중간에 iCloud `스튜디오박스/행사사진/260212 행사 B STRX SJ 복사본`에도 같은 사진이 있었다), 카탈로그 `~/photo-select-data/catalogs/PILOT.cocatalog`
- 행사 A: 행사 폴더 `~/photo-select-data/events/260223_행사 A_seg400`, 카탈로그 `~/photo-select-data/catalogs/PILOT2.cocatalog`

**단, 카탈로그는 사진 경로를 기억하고 있어서 폴더를 옮기면 Capture One에서 오프라인으로 보인다.** 내보내기(`export_labels.py`)는 카탈로그 DB만 읽으므로 사진이 오프라인이어도 라벨은 읽힌다.

결과(`labels_raw.csv`: 파일, 별점, 컬러 태그 번호, 색 이름)를 아래 최종 형식으로 바꾼다.

## 6. 이 데이터로 할 수 있는 것과 한계

| 항목 | 내용 |
|---|---|
| **할 수 있는 것** | 145장 중 B 건수와 사유 분포 파악, 오탐률(최종 A컷 16장이 걸리는지, 표정 주의 컷이 걸리는지), 정탐률 대략치 |
| **한계 1: 양** | 145장이고 B가 몇 장 나올지 모른다. B가 10~20장 이하이면 정탐률은 **참고치**일 뿐이다 |
