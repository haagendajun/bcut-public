# G2 관문 점검 (Phase 2: Capture One 연동)

점검: 2026-10-19. 결론: **조건부 통과.** 데이터를 지키는 핵심(별점·태그 불변, 되돌리기, 키워드 없을 때 중단)은 실기로 확인했다. 1500장은 직접 재지 못했고(추정으로 3분 기준 충족), 일부 오류 상황은 실기로 시험하지 못했다. Phase 3으로 넘어갈 수 있고, 아래 조건은 Phase 3~4에서 닫는다.

환경: Capture One **16.7.1.11**, 시험용 카탈로그 `bcut-test`(20장)와 `bcut-test-400`(EVENT_A 400장)에서만 시험했다. 실제 작업 카탈로그는 열지 않았다. 테스트 368개 통과(1개는 실기 전용이라 건너뜀), lint 통과.

## 1. 조건별 결과

| 조건 | 결과 | 근거 |
|---|---|---|
| 기존 별점·컬러 태그 변경 0건 | **통과** (표본 작음) | `apply`는 `apply keyword`만 호출하고 별점·태그를 쓰는 코드가 없다. 반영 직후 자동 검증이 이번 실행 직전 값과 비교한다. 실기: `bcut-test-400` 60컷 반영 전후 별점·태그 변화 0, `bcut-test`에서 별점 4·2가 이미 있는 컷을 지나 반영했을 때 유지. **별점이 0이 아닌 컷에서 실기로 확인한 것은 2컷뿐** |
| `rollback` 후 원래 상태 복구 | **통과** | 실기: `bcut-test`·`bcut-test-400` 모두 되돌린 뒤 시작 상태와 정확히 같음(400장: 60컷·키워드 120건). 반영 후 사용자가 바꾼 별점·태그·키워드는 건드리지 않고 알림(실기, 사용자 수정은 스크립트로 흉내 냄). 중간에 멈춘 뒤 `rollback`도 가짜 브리지로 확인 |

| 전용 키워드가 없는 카탈로그에서 `apply`가 변경 0건으로 안내하고 중단 | **통과** | 실기 2회: `bcut-test`(키워드 3개 없음), `bcut-test-400`(`bcut-blur` 없음, 실제 흔들림 컷 때문). 변경·백업 파일 모두 없음, 없는 키워드 이름과 안내서 경로 출력 |
| 오류 시나리오에서 데이터가 훼손되지 않음 | **부분 확인** | 쓰기 전에 항상 백업을 저장하고, 못 저장하면 아무것도 바꾸지 않음. 가짜 브리지로 확인: 시간 초과로 중간에 멈춤(부분 반영 알림, 같은 명령으로 이어서 하기, 중복 없음, rollback), 백업 저장 실패, 카탈로그 백업 실패, 다른 카탈로그, 깨진·없는 백업. **실기:** 잘못된 카탈로그 이름만. **실기로 못 한 것:** Capture One 미실행, 열린 카탈로그 없음, 카탈로그 잠김, 자동화 권한 거부 |

## 2. 조건 (닫는 시점)

1. **1500장 직접 측정**: 시간 기준은 각각 3분 이내로 확정되었고 추정으로는 충족한다. 실제 큰 행사에서 직접 재서 확인한다 (Phase 4). rollback의 여유가 작으니 초과하면 읽기 개선(조건 6)을 먼저 한다.
2. **오류 상황 실기 시험**(미실행, 권한 거부 등)은 앱을 끄거나 권한을 빼야 해서 아직 안 했다. Phase 3 운영 안내(runbook)를 쓸 때 시험한다.
3. **모든 앨범의 화면 확인**: 8개를 화면에서 한 번씩 열어 본다.
4. **갱신 캐시 정지의 원인**은 모른다. 앨범이 안 맞으면 Capture One을 껐다 켜라는 안내만 있다. 실제 행사에서 다시 나타나는지 기록한다.
5. **Capture One 버전 고정**: 16.7.1.11에서만 확인했다. 업데이트 전에 T0.5의 7개 시험을 다시 돌린다 (R7).
6. 읽기 시간 개선 여지: `commit`·`rollback`이 카탈로그를 두 번 읽는다. 대상 컷만 읽게 하면 줄일 수 있다.

## 3. 사용자에게 생긴 일 (운영 부담)

- **카탈로그마다 전용 키워드를 한 번 직접 만들어야 한다**(스크립트로 만들 수 없음). 이번 리포트에 흔들림 컷이 있어 `bcut-blur`도 필요했다. 사유별 키워드 6개를 미리 모두 만들어 두는 편이 안전하다([capture-one-setup.md](capture-one-setup.md)).
- 앨범이 비어 보이면 Capture One을 껐다 켠다.
