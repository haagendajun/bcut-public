# Capture One 준비: 전용 키워드 만들기 (한 번만)

`bcut apply`는 사진에 **전용 키워드**를 붙입니다. Capture One은 스크립트로 새 키워드를 만들 수 없어서, **카탈로그마다 한 번 직접 만들어 두어야** 합니다. 없으면 `apply`는 아무것도 바꾸지 않고 멈추며 어떤 키워드가 없는지 알려 줍니다.

## 만들 키워드 (6개, 접두어 `bcut-`)

| 키워드 | 붙는 컷 |
|---|---|
| `bcut-candidate` | B컷 후보 (등급) |
| `bcut-review` | 사람이 확인 (등급) |
| `bcut-eyes_closed` | 눈 감김 사유 |
| `bcut-exposure` | 노출 사유 |
| `bcut-blur` | 흔들림 사유 |
| `bcut-out_of_focus` | 초점 실패 사유 |

## 앱의 "Capture One에도 표시하기"용 키워드 (3개, 2026-10-20 추가)

앱의 나누어 담기 창에서 "Capture One에도 표시하기…"를 쓰려면 아래 3개도 같은 방법으로 만든다. 이름은 **정확히** 같아야 한다.

| 키워드 | 붙는 사진 |
|---|---|
| `bcut-셀렉` | 훑기에서 셀렉(S)한 사진 |
| `bcut-보류` | 보류(M)한 사진 |
| `bcut-버릴컷` | 버릴 컷(X)으로 표시한 사진 |

**세션에서도 같다:** 키워드는 문서(카탈로그 또는 세션)마다 한 번 직접 만든다. 세션은 카탈로그 백업이 없고, 앱이 만드는 되돌리기용 기록(`bcut-backup.json`)으로 되돌린다.

(`dry-run`에서 "카탈로그에 전용 키워드가 없다: …"라고 알려 주는 것만 만들어도 됩니다.)

## 만드는 방법 (Capture One 16)

1. 반영할 **행사 카탈로그**를 연다.
2. 오른쪽 도구 탭의 **메타데이터 → 키워드** 도구를 연다.
3. 사진 **1장만** 선택한다.
4. 키워드 입력칸에 이름(예: `bcut-candidate`)을 입력하고 Return을 누른다. 키워드가 만들어지고 선택한 1장에 붙는다.
5. 6개를 반복한다. 이름은 **정확히** 위와 같아야 한다.
6. 방금 붙은 키워드는 **그 사진에서 지우거나 그대로 둬도 된다.** 지우면 키워드 목록에는 남는다. (그대로 두면 `bcut apply`가 그 컷에 같은 키워드를 이미 붙은 것으로 보고 건너뛴다.)

## 확인

`bcut apply --folder … --catalog … ` (dry-run)이 "카탈로그에 전용 키워드가 없다"를 더 이상 알리지 않으면 준비가 끝난 것이다.

## 문제 해결: 앨범이 비어 있거나 장수가 안 맞을 때

`bcut apply`나 `bcut albums` 직후에 스마트 앨범이 비어 있거나, 이미지 브라우저가 폴더에서도 비어 보이면 **Capture One을 껐다 켠다** (카탈로그의 데이터는 그대로다). 시험에서 이 증상이 한 번 나타났고 재시작으로 모두 정상으로 돌아왔다.
